# 邮箱应用 (MailBox Pro) Spec

## Why
用户需要一个类似网易邮箱大师的完整网页邮箱应用，支持多账号管理、邮件收发、文件夹管理等传统邮箱功能。界面需精心设计，拒绝 AI 味审美，追求独特的视觉风格和高品质的交互体验。

## What Changes
- **新建** 完整的 React 前端邮箱应用，包含登录/注册、邮箱列表、邮件详情、写邮件等页面
- **新建** Node.js Express 后端 API 服务，支持 IMAP/SMTP 邮件收发
- **新建** SQLite 数据库存储用户、邮箱账号、邮件缓存等数据
- **新建** 自定义设计系统，基于「Studio No.5」主题色方案，使用 Lexend + Fraunces 字体组合

## Impact
- Affected specs: 无（全新项目）
- Affected code: `/workspace/email-app/frontend/`, `/workspace/email-app/backend/`

## ADDED Requirements

### Requirement: 用户认证系统
系统 SHALL 提供用户注册和登录功能，使用 JWT 进行身份认证。

#### Scenario: 用户注册
- **WHEN** 用户提供邮箱地址和密码进行注册
- **THEN** 系统创建账号并返回 JWT token

#### Scenario: 用户登录
- **WHEN** 用户提供正确的邮箱和密码
- **THEN** 系统返回 JWT token 并跳转到邮箱主页

### Requirement: 多邮箱账号管理
系统 SHALL 支持添加多个第三方邮箱账号（IMAP/SMTP），并可以在账号间自由切换。

#### Scenario: 添加邮箱账号
- **WHEN** 用户在设置中添加 IMAP/SMTP 账号信息
- **THEN** 系统保存账号配置并开始同步邮件

#### Scenario: 切换邮箱账号
- **WHEN** 用户点击侧边栏中的账号头像或名称
- **THEN** 邮箱列表切换为该账号的邮件

#### Scenario: 删除邮箱账号
- **WHEN** 用户在设置中删除已添加的账号
- **THEN** 系统移除该账号及关联的缓存数据

### Requirement: 邮件收件箱
系统 SHALL 展示当前选中账号的收件箱邮件列表，支持分页加载。

#### Scenario: 查看收件箱
- **WHEN** 用户进入收件箱
- **THEN** 显示邮件列表，包含发件人、主题、摘要、时间

#### Scenario: 邮件已读/未读状态
- **WHEN** 用户点击某封邮件
- **THEN** 该邮件标记为已读，视觉样式随之更新

### Requirement: 邮件详情查看
系统 SHALL 展示选中邮件的完整内容，包括发件人、收件人、主题、正文和附件信息。

#### Scenario: 查看邮件详情
- **WHEN** 用户点击邮件列表中的某封邮件
- **THEN** 右侧或中间区域展示完整邮件内容

### Requirement: 写邮件与发送
系统 SHALL 提供邮件撰写界面，支持收件人、主题、正文编辑，并通过 SMTP 发送。

#### Scenario: 撰写并发送邮件
- **WHEN** 用户填写收件人、主题、正文并点击发送
- **THEN** 邮件通过 SMTP 发出，存入已发送文件夹

#### Scenario: 草稿保存
- **WHEN** 用户撰写过程中关闭编辑器
- **THEN** 内容自动保存为草稿

### Requirement: 邮件回复与转发
系统 SHALL 支持对收到的邮件进行回复和转发操作。

#### Scenario: 回复邮件
- **WHEN** 用户点击回复按钮
- **THEN** 打开编辑器，自动填入原发件人和 Re: 主题

#### Scenario: 转发邮件
- **WHEN** 用户点击转发按钮
- **THEN** 打开编辑器，自动填入 Fwd: 主题，保留原文

### Requirement: 文件夹管理
系统 SHALL 支持收件箱、已发送、草稿箱、废纸篓等标准文件夹。

#### Scenario: 查看不同文件夹
- **WHEN** 用户点击侧边栏文件夹
- **THEN** 邮件列表切换为该文件夹的内容

#### Scenario: 删除邮件
- **WHEN** 用户删除邮件
- **THEN** 邮件移入废纸篓

### Requirement: 邮件搜索
系统 SHALL 支持在当前邮箱中搜索邮件。

#### Scenario: 搜索邮件
- **WHEN** 用户在搜索框输入关键词
- **THEN** 显示匹配的邮件列表

### Requirement: 界面美观与设计系统
系统 SHALL 采用「Studio No.5」设计系统，使用精心调配的配色和字体，呈现独特的暖调复古工作室美学。

#### Scenario: 整体视觉一致性
- **WHEN** 用户浏览应用的任何页面
- **THEN** 所有组件遵循统一的设计语言、配色和间距规范

#### Scenario: 侧边栏设计
- **WHEN** 用户查看侧边栏
- **THEN** 显示深墨蓝底色、暖铜金装饰线、清晰的账号头像和文件夹列表

#### Scenario: 邮件卡片
- **WHEN** 用户查看邮件列表
- **THEN** 每封邮件为独立卡片，带有精致的边框和悬停效果
